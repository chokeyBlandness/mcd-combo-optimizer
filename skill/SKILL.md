# 麦门组合优化器（McDonald's Combo Optimizer）

## 触发场景
- 「用 40 元帮我配一份不超过 900 大卡、有主食有饮料的麦当劳套餐」
- 「50 块在麦当劳怎么吃蛋白质最多？」
- 「两个人 80 元拼单，怎么点最营养？」

## 工作流程（必须真实调用麦当劳 MCP）
1. **取菜单**：调用 `query-meals`，获取当前门店可售餐品（`code` / `name` / `price` / 分类 / `tags`）。
2. **取营养**：调用 `list-nutrition-foods`，获取每个餐品的能量、蛋白质、脂肪、碳水等。
3. **合并数据**：按 `code` 将两份结果合并为 `items` 列表，字段对齐：
   `{code, name, price, energy, protein, fat, carb, sodium, tags}`。
4. **求解最优组合**：调用本地优化器
   `python3 src/optimizer.py --budget <元> --calorie-cap <kcal> --people <N> --require-main --require-drink --json`
   也可把合并后的 JSON 通过 `--stdin` 传入。
5. **核验价格**：调用 `calculate-price`，将最优组合的商品列表传入，叠加可用优惠券，核验应付总价。
6. **呈现结果**：向用户展示组合明细、总价、营养汇总、每元营养值，并提示「仅供参考，以官方实时为准」。

## 优化目标与约束
- **目标**：`max Σ(蛋白质_i + 0.3 × 能量_i / 100)`（营养性价比代理指标）
- **约束**：总价 ≤ 预算；总能量 ≤ 热量上限（可选）；至少 1 主食 + 1 饮料（可选）
- **求解**：优先 PuLP 精确整数规划；未安装时自动回退零依赖启发式。

## 注意事项
- 菜单 / 价格 / 营养以麦当劳 MCP 实时返回为准；无 Token 时可用 `src/data/menu_sample.json` 演示。
- 输出仅供参考，**不构成营养 / 医疗建议**；请理性点餐、均衡饮食。
- 配置文件只允许环境变量占位符 `${MCD_MCP_TOKEN}`，禁止写入真实 Token。
